Forget
Version 0.1.0 · byggd på Chromium (Electron) + Tor

Anonym webbläsare som glömmer allt. All trafik går genom Tor-nätverket, och hela sessionen — historik, kakor, cache, nedladdningar — ligger i datorns minne och raderas när du stänger fönstret. Inget konto, ingen molntjänst, ingen statistik: vi kan inte se vad du gör, ens om vi ville.
